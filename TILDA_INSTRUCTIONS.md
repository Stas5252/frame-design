# Инструкция по переносу и привязке страниц к Tilda

Все страницы разработаны в чистом, автономном формате (HTML5 / CSS3 / Vanilla JS) с точным сохранением премиального стиля **Frame Design** (шрифты *Cormorant Garamond* + *Inter*, палитра тёмного шоколада, графита и светящейся латуни).

Каждая страница полностью готова как для локального запуска и хостинга, так и для вставки в **Tilda** через стандартный блок **T1370 (HTML-код)**.

## 2. Пошаговая инструкция по добавлению на Tilda

### Шаг 1: Создание страницы в панели Tilda
1. В вашем проекте Tilda нажмите **«Создать новую страницу»**.
2. В настройках страницы задайте:
   - **Заголовок (Title)**: например, `О компании — FRAME DESIGN`
   - **Описание (Description)**: описание из тега `<meta name="description">`
   - **Адрес страницы (URL)**: например, `about`, `salon`, `tech`, `portfolio`, `contacts`.

### Шаг 2: Добавление HTML-блока
1. Нажмите **«Добавить блок»** → выберите категорию **«Другое»** → найдите блок **T1370 «HTML-код»**.
2. Нажмите кнопку **«Контент»** в блоке T1370.
3. Откройте нужный `.html` файл в любом текстовом редакторе (VS Code, Блокнот и т.д.), скопируйте всё содержимое файла и вставьте в поле кода блока T1370.
4. Нажмите **«Сохранить и закрыть»**.

### Шаг 3: Загрузка изображений на Tilda
1. Фотографии из папки `images/` можно загрузить во внутреннее хранилище Tilda (через стандартный блок изображений или настройки проекта) либо разместить на вашем сервере/CDN.
2. При необходимости замените относительные пути `images/...` в HTML-коде на полученные прямые ссылки Tilda CDN (`https://static.tildacdn.com/...`).

### Шаг 4: Публикация
1. Нажмите **«Опубликовать»** в верхнем правом углу Tilda.
2. Проверьте отображение страницы на компьютере и мобильных устройствах.

## 3. Настройка форм и заявок

- Формы на страницах `salon.html`, `contacts.html` и в модальном окне `portfolio.html` сверстаны в премиальном темном стиле.

  - Вы можете использовать стандартный виджет форм Tilda или настроить отправку через `fetch()` на ваш Webhook / Telegram-бота.
