# FRAME DESIGN — Премиальная мебель на заказ

Официальный многостраничный сайт премиального мебельного производства **FRAME DESIGN** (г. Калининград).

## 🔗 Онлайн демо (GitHub Pages):
[https://stas5252.github.io/frame-design/](https://stas5252.github.io/frame-design/)

---

## 🏛 Структура страниц:
1. **Главная (`index.html`)** — 1 в 1 по дизайну с референсом, интерактивный первый экран, статистика со свечением латуни, каталог 5 направлений с 3D-тилтом, пульсирующая печать.
2. **О компании (`about.html`)** — 11 ключевых компетенций, отказ от субподряда, полный цикл от распила до монтажа.
3. **Наш салон (`salon.html`)** — экспозиция 200+ видов фасадов, центральная стена Frame Design, форма бронирования визита.
4. **Технологии (`technologies.html`)** — лазерное 3D-сканирование помещений с точностью до 0.5 мм, цифровая цепочка CAD/CAM/CNC.
5. **Контакты (`contacts.html`)** — интерактивные Яндекс Карты, кнопки быстрого построения маршрута (Яндекс Карты, 2ГИС, Google Maps), охраняемый паркинг, форма записи.
6. **Портфолио (`portfolio.html`)** — галерея реализованных проектов с реальными фотографиями, фильтрация по категориям (Кухни, Гостиные, Гардеробные, Санузлы, Зеркала и декор), модальные окна Quick View.

---

## 🛠 Стек и технологии:
- **Семантический HTML5** + адаптивная CSS3 верстка (Grid, Flexbox, CSS Variables).
- **Типографика**: оригинальный шрифт `TildaSans` / `TildaSans Italic`.
- **Vanilla JavaScript** (аппаратное ускорение анимаций 120fps, IntersectionObserver, 3D tilt).
- **Интеграция с Яндекс Картами**.
- **SEO-оптимизация**: Schema.org микроразметка, Open Graph мета-теги.
- Полная совместимость с Tilda (блок **T1370**).
